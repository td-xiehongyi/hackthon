# 三校区地图方位校正说明 v2

日期：2026-09-26。

本轮依据用户反馈修正：麓南、潇湘校区建筑与相对方位有误，建筑及运动场朝向不正确。取消“一张屏幕放下全部地图”的假设，优先保持地点关系与地面轴向。原版仅保留作修改前对照，不能继续作为准确地图底图。

## 本轮交付

- `三校区总图-方位校正版-v2.png`：北向上连续大范围概念图，仅标注校区及主要大水体，用于检查宏观位置。
- `麓南校区-方位校正版-v2.png`：麓南及邻接区域的纵向分区图，包含建筑标签；文法楼西侧楼群标签和半月湖水陆形态经过局部修订。
- `潇湘校区-方位校正版-v2.png`：运动区与南部教学区的分区图。
- `方位校正生成提示词-v2.md`：实际成功采用的提示词与局部修订指令。生成方式为 Codex 内置图像生成工具。
- `方位校正版文件校验-v2.json`：交付 PNG 的尺寸、格式、文件大小与哈希记录。

两张分区图有重叠区域，且输出比例不同，用于分别放大审阅，不能直接首尾拼接成无缝地图。总图与分区图也不是逐像素配准的测绘成果。

### 本轮生成后的检查

已对照参考图目视复查：运动场长轴、文法楼与运动场东西关系、二教/半月湖/文法楼的南北关系、麓南宿舍向南延伸、潇湘主场与体育馆相对位置、靳江路上下分区、图书馆长轴和临水侧、玉带湖环绕教学区的方向、后湖与教学区之间的街区间隔。已修正麓南楼群标签指向及半月湖北侧陆地连接；PNG 已实际解码并通过文件完整性检查。

这次检查不等于逐栋实测验收：细小背景楼栋、门口台阶、入口朝向、岸线精度及最近施工变化仍不作准确性承诺。尤其不能把像素插画中的屋顶细节当成校园最新现状。

## 采用的核对方式

1. 取得覆盖三校区、后湖、湘江的大范围北向上卫星俯视图，保留原图、服务来源及地理范围数据。
2. 用校方平面图识别建筑归属，用 2025 年潇湘校区马拉松路线图复核运动区与教学区的连接。
3. 用校方航拍与建筑照片判断屋顶和楼体形态。斜拍照片只用于外观，不把照片中的上、下、左、右直接当成北、南、西、东。
4. 地图表现改为屋顶与建筑轮廓占主导的北向上俯视画法，停止把所有建筑正立面都转向画面下方。

卫星影像服务未在这次导出中提供每个像元的拍摄日期，因此没有将其描述为 2026 年最新现场状态。它用于道路、水系、建筑轮廓与长轴方向；新旧名称另用校方资料核对。在建项目没有据此推断为当前已完工。

| 麓南校区整体 | 被压扁为横向景点集合 | 保留北侧住宅、礼堂/二教、半月湖、文法楼/运动场、南部宿舍的南北纵深 |
| 麓南运动场 | 长轴被画成东西向 | 依平面图与卫星轮廓恢复大致南北向；西侧为球场，文法楼在更西侧 |

| 第二教学楼 | 与片区关系过度简化 | 保留在半月湖北侧，长条主体大致东西向；与南侧教学建筑分开 |
| 文法楼 | 被泛化为统一现代教学楼群 | 作为独立地标，位于半月湖南偏西、运动场西侧；保留长条翼部及向南延伸的体量 |

| 潇湘校区整体 | 体育场、教学楼、图书馆被并排摆放 | 西侧狭长运动区与东南侧教学区组成展开的空间关系，不能互换 |
| 潇湘体育场 | 长轴横向、主看台位置随构图变化 | 恢复大致南北向长轴，主看台/大顶棚在西侧；体育馆在其东北方向，单独表达 |
| 运动场副场 | 旧版遗漏 | 位于主体育场以北，保持与球场、体育馆的前后顺序 |

| 潇湘教学楼群 | 被画成孤立横向楼牌 | 按卫星轮廓保留北侧条形楼、内部翼部及南侧弧形楼体的组合；仅在相邻范围内概括 |
| 潇湘图书馆 | 被画成东西向宫殿式楼体 | 主体长轴大致南北向，在教学楼群以东、水面以西；西侧是校园前坪，东侧临水 |
| 玉带湖及内部水系 | 被改成图书馆南侧一个大圆湖 | 保留教学区东侧、南侧连续弯曲水带及图书馆东侧的北部水面 |
| 校间连接 | 未表现清水路、湿地与天桥关系 | 根据卫星图和校方航拍，保留麓南宿舍侧与潇湘运动区之间的实际斜向跨越关系 |
| 后湖、湘江 | 视觉上过度贴近、加入未核实桥梁 | 后湖与湘江之间保留街区/绿地间隔；去掉无依据的跨湘江装饰桥 |

## “朝向”的核对范围

- 已有依据：北向、建筑主体长轴、屋顶/楼体轮廓的地面旋转方向、运动场长轴、看台所在侧、主要桥梁的跨越方向。
- 不混同：建筑长轴不等于主入口朝向。参考图无法确认的入口、台阶、门禁通行方向，不用一个统一朝南的正面造型补猜。
- 剩余边界：生成图片仍可能存在局部位移或细节误差；它不具备直接用于导航、测量或碰撞判断的精度。正式网页需使用统一坐标下的道路/建筑轮廓数据约束素材位置与旋转。

## 后续网页约束（记录需求，不代表本轮已开发网页）

- 地图是可拖动、缩放的大场景，初始只显示局部；校区按钮负责定位，不能靠挪动校区来适应屏幕。
- 三校区使用共同的北向与地面坐标体系；分区图用于详细审阅，不可按相同像素大小直接拼接，必须结合各自地理范围。
- 像素建筑与文字标签分离。标签保持易读，建筑按底图方向摆放；不能为让标签朝正而旋转建筑。
- 教学楼群是交互汇总入口。真实楼栋归属保存在数据中，不跨主路、水系或校区合并。
- 生成图只提供视觉概念。角色可走区域、碰撞和建筑入口按核对后的几何位置独立制作。
