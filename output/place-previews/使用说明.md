# 中南大学像素校园 · 地点交互 HTML 预览

交付日期：2026-09-26。此目录交付界面与交互效果预览，未开发正式校园应用或本机数据服务。

## 打开

双击 **中南大学像素校园-地点交互预览.html**，用 Chrome 或 Edge 打开。

该 HTML 已内嵌样式、脚本、最终地图和参考照片，可以单独复制到其他目录打开，无需联网、安装依赖或启动服务。顶部按钮为设计评审使用的地点切换器，正式应用仍需到达地点后主动互动。

## 包含的界面

| 地点 | 预览内容 |
| --- | --- |
| 潇湘教学楼群 | 个人课表、楼座筛选、单双周切换、完整周课表、课表管理、CSV 校验流程、新增表单、独立相册 |
| 潇湘图书馆 | 地点基本信息、介绍缺失状态、外观参考、独立相册 |
| 潇湘操场 | 活动关键词/类别/校区/日期筛选、活动详情、历史活动标识、社团目录、独立相册 |
| 共用状态 | 演示数据、空状态、失败状态与重试、选图、放大查看、关闭弹窗、返回校园 |

试用路径：教学楼群 → 示例楼座 B → 上一教学周（查看单双周差异）；操场 → 岳麓山校区（查看活动实际地点）；任一地点 → 地点相册 → 选择图片预览。

## 数据与功能边界

- 课程、学期、教师、楼座、社团、活动均为明确标注的演示数据。固定演示时间为 2026-09-26 14:00，不构成实时活动查询。
- 地点身份沿用 `docs/contracts/campus-v1.d.ts` 的三个固定 placeId。示例楼座 A/B 不是已核实的实际楼座清单。
- 图书馆正式介绍、来源及开放时间没有经过本次核验，界面保留缺失状态。
- 选图只读取到当前页面内存，刷新后清空；未写入项目相册，也不支持跨浏览器共用。本预览单图暂限 15 MB 以避免卡顿，不作为正式图片容量约定。
- CSV 导入、新增课程仅演示表单和反馈，不执行真实导入或保存。导出按钮可下载明确标注的演示 JSON，不是已确定的正式备份格式。
- “定位”保留未标定提示；“返回校园”关闭面板并显示地图预览。未实现角色、真实入口、移动、碰撞、遮挡或安全落点。
- Esc 仅为当前预览的关闭约定，没有变更正式需求中的待确认快捷键。
- 三幅顶部像素背景由简单矢量图形绘制，标注为示意；不是经过核实的室内或操场实景。
