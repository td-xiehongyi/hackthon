# Character Playground（角色模块原型）

这是校园探索项目里"角色"这一小部分的独立原型，用来验证像素角色的**8方向 × idle/walk/run 动画**能不能正常播放。

**这不是最终项目**，也没有接入任何 3D/2D 引擎或最终代码仓库。最终技术栈还没确定（队友的 MVP 还在做），所以这里只是一个可以独立打开、独立测试的小页面，方便在技术栈定下来之前先把角色的动画数据和播放逻辑跑通。

## 怎么运行

不需要装任何东西，也不需要起服务器。直接用浏览器打开：

```
playground/index.html
```

双击这个文件，或者拖进浏览器窗口都行。打开后可以：

- 点击左侧按钮切换 **Idle / Walk / Run** 三种状态
- 用方向键盘（3×3 排列）切换 8 个朝向，其中 **上 / 下 / 左 / 右** 是最常用的四个主方向，另外四个斜向也留着（如果后续场景发现斜着走太生硬要用到）
- 下方有一个 8 方向总览面板，8 个方向同时播放同一个状态，方便肉眼检查有没有镜像错位、朝向不对的问题
- 右上角"暂停"按钮可以定格看某一帧

## 目前的角色是什么

**占位造型，不是最终美术**。用代码画的一个圆润小生物（暖橙色身体、大眼睛、白色肚皮），目的是先把"8方向 + 3状态"这套动画系统跑通、验证走路/奔跑动作是否自然，还没有做成组里想要的最终角色形象（比如带校徽的 polo 衫等细节）。

动画原理：这类没有明显关节的圆润角色，走路/奔跑不是靠四肢摆动，而是靠身体整体的挤压拉伸（squash and stretch）+ 左右重心摇摆来表现"移动感"，这是这类角色动画的标准做法。

## 目录结构

```
pixel-character/
├── playground/              # 查看器 — 打开这里的 index.html 即可运行
│   ├── index.html           # 页面 + UI 控制（状态按钮、方向盘、8方向总览）
│   └── character-player.js  # 播放逻辑：给定"状态+方向"，算出该显示哪一帧、多久切下一帧
│                             # 完全不知道角色长什么样，只认 assets/ 里的数据格式
├── assets/                  # 角色素材（数据），与控制逻辑完全分离
│   ├── character-sheet.png  # 雪碧图本体：8方向 × (idle 2帧 + walk 4帧 + run 6帧)
│   ├── character-meta.js    # 帧坐标 + 动画时长数据，playground 直接用 <script> 加载这个
│   ├── character-meta.json  # 同样的数据，纯 JSON 格式（以后接入真正的项目/引擎时可能更方便用这份）
│   └── frames/               # 每一帧的单独 PNG（按方向/状态分文件夹），方便肉眼逐帧检查，不参与实际播放
└── tools/
    └── generate-sprites.js  # 构建脚本：重新生成上面 assets/ 里的所有文件
                              # 运行：node tools/generate-sprites.js
```

**素材和逻辑是怎么分开的**：`character-player.js` 只依赖 `character-meta.js` 里约定好的数据结构（帧宽高、每个方向/状态对应雪碧图里的坐标、每帧播放时长），不关心图片具体画的是什么。以后换成正式的角色美术，只要新的雪碧图和 meta 数据保持同样的结构，播放逻辑完全不用改。

## 想改角色/动作怎么做

角色的形状、颜色、动作参数都在 `tools/generate-sprites.js` 里，改完重新跑一遍脚本就会覆盖 `assets/` 下的产出：

```bash
node tools/generate-sprites.js
```

如果后面换成真正手绘/找到的角色素材（而不是代码画的占位角色），只要把新的雪碧图按 `character-meta.js` 里描述的坐标规则对齐，不需要跑这个脚本，也不需要碰 `playground/` 里的任何代码。

## 当前已知的局限

- 角色造型是代码拼出来的占位图形，精细度有限，不是最终美术
- 8方向都是从 5 套独立朝向（正面/背面/侧面/斜前/斜后）镜像出来的，如果后续想要更细腻的斜向姿态，需要单独调整 `generate-sprites.js` 里 `front3q`/`back3q` 的绘制逻辑
- 还没有"骑电动车"之类的额外形态，这个待角色本体定下来后再单独做
