# 照片蓝眼长毛猫｜E3 完整候选素材包

日期：2026-09-27。固定 ID：`photo-point-cat`。版本：`0.3.0-rc.1`。
状态：E1 外观获用户确认；E2 行走、骑行及地图视觉预览获“符合”反馈。本包是**接入候选**，像素边缘、动画和游戏运行验收尚未通过。

## 内容与来源

- `walk-cycle.png`、`ride-cycle.png`、`manifest.json` 和 `PROMPTS.md` 从同角色 E2 目录逐字节复制，未改变已展示的图像。两张 PNG 共 32 个源帧；候选 manifest 提供 16 个状态入口和 40 次帧引用。
- 待机复用每方向的首帧。步行移动每帧 180ms，骑行移动每帧 160ms；这些是候选播放节奏，不代表已验收。
- `VERSION.json` 记录版本、确认范围、各源文件校验值与未通过项。预览网页和截图保留在 E3 目录供审阅，不放入运行 ZIP。
- `photo-point-cat-0.3.0-rc.1.zip` 仅包含两张 PNG、manifest、PROMPTS、SOURCE 和 VERSION 六个文件，路径均位于 ZIP 根目录。
- 参考为用户提供的两张猫照片与项目角色风格。原照片未复制进项目或 ZIP；无分层绘图工程或三维模型。

## 接入边界

1. 集成方检查本候选包后，才可将必要运行文件复制到 `public/characters/photo-point-cat/`，并设置 `/characters/photo-point-cat` 的加载映射。
2. 需在当前地图复核步行和骑行各自的等比显示尺寸。E2 页面只叠放了候选视觉比例，没有给出已验收的运行比例；图片画幅不是碰撞范围。
3. 逐帧锚点仍是候选数值。接入后检查行走四方向、Shift 骑行切换、停止保留朝向、斜向速度、足底和车轮落地点、两模式碰撞、建筑/树木遮挡及输入中断。
4. 首页当前仅展示 E1 静态猫图，不能据此认为 E3 已能试走。本阶段未修改共享代码、公共加载器、地图或 `public/characters/` 运行目录。

## 已验证与已知问题

- 项目现有 manifest 校验器检查了 2 张图、16 状态、40 次帧引用、sheet 引用、帧范围和锚点；PNG 实际尺寸与声明一致。ZIP 成员与源文件逐一哈希比对见 `archive-check.json`。
- `preview.html` 的八张卡片、暂停、单步、待机/移动、地图模式和方向选择已在本机 Edge 通过页面检查；截图是静态取样，不等于游戏运行验收。
- PNG 主体和边缘包含大量半透明像素，并可见少量红黄彩色杂边；正式像素清理未完成。
- 行走步态差异有限，骑行车轮和车身变化较轻；待机没有专用姿态。帧间尾巴、身体和车辆细节仍需精修。
- 锚点稳定、方向间大小、WASD/Shift 实际操作、碰撞、遮挡和失焦暂停尚未在游戏中通过验收。
