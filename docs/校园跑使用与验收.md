# 校园跑：使用与验收

更新：2026-09-27

## 入口与玩法

进入校园，靠近潇湘校区体育场（副场），按 E 打开地点页，选择“校园跑”，点击“开始校园跑”。

- 沿用本次进入校园时选中的角色及其行走动画。
- WASD、方向键或按住屏幕方向按钮移动。
- 从底部起点向右出发，沿右侧弯道向上，逆时针依次通过 1—7 号打卡点，最后回到“终”点；进度达到 8/8 后显示“校园跑成功！你已完成一圈。”
- 黄色圆点表示下一个目标；绿色勾表示已经完成。只能在跑道内移动，草坪和场外不可通行。
- 连续按住任一侧 Shift（或屏幕上的“按住骑电动车 · Shift”按钮）满 0.75 秒，停止移动并开始提醒。短按不会触发，松手、窗口失焦或页面隐藏会清零计时；左右 Shift 重叠按住算同一次持续骑行。
- 提醒角色出现在用户指定的操场左下区域，以真实透明底叠在场景上，用 0.35 秒从透明逐渐出现。淡入完成后，从角色头顶出现“操场禁止骑电动车！！！”气泡。操场保持可见，不再使用全屏遮罩弹窗。
- 按住期间显示所选角色的骑行动画，以原步行速度的 2 倍移动；骑行经过打卡点不记入步行打卡。
- 点击“知道了，继续跑步”或按 Escape 关闭警告，保留位置与打卡进度。移动按键会清空，需要重新按下。
- “重新开始”和“再跑一圈”重置本圈。离开校园跑页签或退出操场后，本圈进度不保存。
- 返回校园后恢复原地图位置；小游戏输入不会移动外面的校园角色。

## 素材与实现

- `public/scenes/campus-running-track-v1.png`：已确认的生成操场图。
- `public/scenes/campus-run-guard-v1.png`：用户提供的原始警告角色图片，保留。
- `public/scenes/campus-run-guard-transparent-v2.png`：内置 image_gen 工具生成的透明底版本，用于场内提醒。已检查 PNG alpha 通道及浏览器中的透明背景；生成提示词见 `output/campus-run-guard-v2-prompt.txt`。
- `src/features/stadium/CampusRun.tsx`：场景、角色动画、按键/触屏控制与警告弹窗。
- `src/features/stadium/campus-run.ts`：跑道边界、顺序打卡、成功与警告状态。
- 入口接在 `StadiumPanel`；所选角色由 `App → PlaceHost → StadiumPage` 传入。

## 边界

这是本机浏览器中的校园跑小游戏，未接真实定位、运动平台、成绩上传或持久化跑步记录。手机窄屏沿用原有左侧信息栏布局，操场画面较小；本轮验证的是桌面 Chrome 的窄屏和指针操作，未验证实体手机。
