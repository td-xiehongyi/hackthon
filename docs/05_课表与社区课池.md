# 课表与社区课池

版本：1.0.0  
日期：2026-09-26  
状态：已实现于教学楼功能页

## 范围变更

最新产品需求要求存储参与用户的课表并汇总课程。本文因此就“课表汇总”覆盖旧文档中“个人课表永不进入服务”的约定。公共社团、活动和地点相册仍按 [本机数据接口](03_本机数据接口.md) 隔离保存，不与课表文件混用。

实现采用两层数据：

1. **个人课表**：当前浏览器站点存储，供周课表、导入导出和离线查看使用。
2. **社区课池**：同源服务按随机安装 ID 保存最新课程快照，读取时只返回去重课程及来源份数。

个人保存成功不依赖社区同步成功。社区接口不可用时，个人课表仍可录入、查看和导出。

## 课程模型

浏览器中每条 `Course` 表示一次排课，而不只是一个课程名称。主要字段为：

| 字段 | 说明 |
|---|---|
| `id` | 浏览器生成的课程记录 ID |
| `name` / `teacher` | 课程名与教师 |
| `weekday` | `1`–`7` 对应周一至周日 |
| `startPeriod` / `endPeriod` | 起止节次 |
| `weeks` | 展开后、排序去重的有效教学周，是计算的事实来源 |
| `weekParity` | `all` / `odd` / `even` / `custom`，用于展示 |
| `location` | 教室或其他地点原文 |
| `buildingId` | 仅在已核验楼座目录能唯一匹配时写入 |
| `buildingName` | 保留导入或手工输入的楼座名称 |
| `tags` | 用户明确填写的兴趣标签；系统不猜测学科 |

实际楼座目录尚未核验，所以当前表单和 CSV 优先保留地点原文，不虚构 A/B/C 座或地图坐标。

## CSV

导入器支持 WakeUp 常用七列格式：

```csv
课程名称,星期,开始节数,结束节数,老师,地点,周数
高等数学,1,1,2,张老师,教学楼201,1-16
```

- 支持 UTF-8 BOM、CRLF/LF、RFC 4180 引号内逗号和换行。
- 支持 `1-16`、`1-8单`、`2-16双`、`1、3、5` 和 `1-5、7-11单、12-16双`。
- 导入先在内存中完整解析并展示错误、提醒和未匹配地点；存在任一错误时禁止提交。
- 默认为追加并跳过完全重复记录；替换前要求用户确认已备份。
- 导出使用 UTF-8 BOM 和 CRLF，并对以 `=`、`+`、`-`、`@` 开头的文本做表格公式注入防护。

## CSU 教务系统辅助导入

教学楼页另外提供“从教务系统导入”入口，面向中南大学 CSU 统一认证后的课表页面。入口只负责打开官方地址
[`https://ca.csu.edu.cn/`](https://ca.csu.edu.cn/)，不会把登录页嵌入项目，也不会代替用户完成认证。建议按下面的用户流程操作：

1. 学生点击入口，在官方标签页自行完成统一认证及验证码/滑块等验证，并进入网上办事大厅的教务服务和“我的课表”。
2. 从已经渲染的课表复制 HTML 表格、TSV/CSV、Markdown 表格或课程文本；也可以下载课表文件，再在导入弹窗中选择 `.csv`、`.tsv`、`.txt`、`.html` 或 `.htm`。Excel 文件先由用户另存为 CSV。
3. 项目前端在内存中调用 `parseCsuScheduleText`（文件内容同样走此解析器）生成预览。解析器识别 CSU 常见中文列名和“上课时间”组合字段，并复用本节 CSV 解析器校验周次、单双周、节次、重复记录及楼座提示。
4. 用户查看错误和提醒后选择追加或替换；确认前不会改动个人课表。成功保存后，才会按“社区课池 API”一节的开关和隐私规则决定是否同步。

### 安全边界

该功能是“用户驱动的辅助导入”，不是服务端爬虫或登录代理。原因是 CSU 统一认证需要用户交互验证，登录会话由浏览器保护，且教务页面没有供本项目跨站直接读取的公开课表接口。因此实现明确遵守以下边界：

- `src/features/teaching/caImport.ts` 不执行 `fetch`、不读取跨域页面或 Cookie，不接收账号/密码，不自动填写表单，不绕过验证码、滑块、二维码或其他访问控制。
- HTML/文本/文件解析在当前浏览器完成；导入文件不会上传。解析前会移除脚本、样式、表单、输入控件，并过滤包含密码、验证码、用户名等敏感标签的行。
- 服务器只会收到用户确认后的标准化课程快照，而且仅在用户开启“匿名汇总”时发送；不会收到 CSU 登录凭据、Cookie、原始登录页或完整原始课表。关闭开关时撤回该浏览器安装 ID 的贡献。
- 若官方页面改版导致列名或文件格式无法识别，用户可以回退到 WakeUp 七列 CSV 或手动录入；解析失败不会覆盖已有课表。

## 社区课池 API

开发与预览服务由 `server/communitySchedulePlugin.ts` 提供同源路由。默认数据文件为 `data/community-schedules.json`；测试可用 `CSU_COMMUNITY_SCHEDULE_FILE` 指向隔离文件。

### `PUT /api/community-schedules/:installationId`

原子替换该安装 ID 的当前学期快照。请求体：

```json
{
  "termId": "current-term",
  "courses": []
}
```

`installationId` 由浏览器首次访问时随机生成。服务端限制单个快照最多 200 条课程、请求体最大 2 MB，并重新校验星期、节次和周次。

### `DELETE /api/community-schedules/:installationId`

撤回该安装 ID 的全部课程贡献。关闭页面中的“匿名汇总”开关时调用。

### `GET /api/community-courses?termId=current-term`

返回指定学期的去重课程：

```json
{
  "termId": "current-term",
  "updatedAt": "2026-09-26T00:00:00.000Z",
  "contributorCount": 2,
  "courses": [
    {
      "id": "shared-...",
      "name": "视觉文化导论",
      "weekday": 4,
      "startPeriod": 5,
      "endPeriod": 6,
      "weeks": [1, 2, 3, 4],
      "contributorCount": 2
    }
  ]
}
```

聚合键包含课程名、教师、星期、节次、有效周、地点和楼座。同一用户的重复记录只计一次。响应不包含安装 ID、用户名或完整原始课表。

## 蹭课计算

对选定教学周，候选课程必须：

1. 在该周实际开课。
2. 与个人课表在星期和节次上无任何重叠。
3. 通过当前的星期、地点、关键字和明确兴趣标签筛选。
4. 不是本人已有课程的相同记录。

结果是“社区课表线索”，不能宣称为学校完整排课、教室实时空闲或旁听许可。

蹭课页会每 30 秒重新读取一次社区课池，也可点击“刷新”立即更新。用户可以在筛选面板的“我的兴趣”中添加关键词；关键词保存在当前浏览器，并匹配课程名、教师、地点和用户填写的课程标签。

## 当前边界

- `current-term` 是单学期占位 ID；没有核验的校历起始日，所以界面要求手动选择教学周。
- 当前课池适合本机或 hackathon 单实例。向公网部署前需加入可验证身份、授权、速率限制、按学期清理和更完整的隐私政策。
- 用户课表条数较小，当前使用浏览器站点存储。如后续加入大型附件、多学期或离线同步队列，再迁移到 IndexedDB。
