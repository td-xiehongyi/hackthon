# ZIP 场景导入

## 使用

启动原项目，在首页点 **导入场景 ZIP**，再选择 `pixel-scene` Skill 生成的 `*.scene.zip`。也可直接打开当前项目地址的 `/#scenes`。

导入的是场景包，包含 `scene.json` 和地图、照片等图片。Skill 安装包和工作台程序包不属于场景包。只有一张图片的 ZIP 也可导入，此时没有交互点。

- 地图保留生成图片的轻微 2.5D 像素效果。
- 点击地图编号或地点列表查看内容；点击地图后，WASD / 方向键移动、Shift 加速，靠近地点按 E。
- 地点支持照片上传；社团地点可添加社团；点评地点可写 1–5 分点评；教室可按课程、时间、教师搜索包内课表。
- 地图只限制外边界，建筑可穿行；不会从图片自动识别建筑、生成碰撞箱或补造课表。
- 返回校园首页后，可以进入原校园地图。

## 保存与备份

每次导入生成一个新的本地场景，保存在当前浏览器来源下的 IndexedDB `csu-imported-scenes-v1`。同一个包重复导入会保留两份，不覆盖原场景；内容修改在成功写入后才显示保存成功。刷新后恢复最近导入的场景，其余场景可以在下拉框切换。

新增照片、社团和点评也保存在这里。清理网站数据、更换浏览器或端口后不会自动同步；使用 **导出场景 ZIP** 备份。导出包仍兼容 Skill 工作台，不含本地 ID、保存版本或浏览器信息。

导入失败保留已打开的场景。多个标签页同时修改同一场景时，过期页面会收到冲突提示，需要刷新后重新操作，避免静默覆盖。

这部分内容独立于原校园地点服务和 Python 工作台的数据目录；导入不修改原校园的地图、课表或点评。

## 格式与限制

支持 `schemaVersion: 1`，`scene.json` 位于 ZIP 根目录或一层外包文件夹中。地图和照片仅支持 PNG、JPEG、WebP；文件路径均为包内相对路径。

上限：ZIP 64 MB、解压总量 64 MB、单张图片 16 MB、清单 2 MB、512 个文件、200 个交互点，每个地点的每类内容最多 500 条。保存时预留 ZIP 文件头空间，以保证导出后可重新导入。图片需能由浏览器解码，最长边不超过 16384，总像素不超过 4000 万。

读取前检查 ZIP 文件头、文件大小、重叠内容、重复路径、越界路径、加密和符号链接。包内 HTML 或脚本不会执行。图片风格和坐标按包内数据展示；导入器不负责图片生成。
