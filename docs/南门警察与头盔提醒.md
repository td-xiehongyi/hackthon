# 南门警察与头盔提醒

## 已实现

- 根据校园跑警察参考图，使用内置 image_gen 生成全身像素风透明角色。
- 当前项目消费二维 PNG 素材，文件为 `public/characters/south-gate-police/standing-v1.png`（1100 × 1430，RGBA）；原警察图片保留。
- 警察脚底位于原图坐标 `(386, 440)`，显示高度 36 原图像素，按脚底深度参与排序。
- 角色正在骑行且进入南门范围 `x=294…394, y=375…457` 时，立即强制下车并暂停移动，警察头顶显示：**同学停下！！！头盔！！！！**。
- 对话框不会自动消失，点击整个对话框后放行；也可聚焦后按 Enter 或空格操作。放行时保持步行，重新按移动/骑行键后通行。
- 步行、原地按 Shift、暂停或浏览地图不触发。
- 同次经过只拦停一次，点击放行并离开外圈 `x=282…406, y=363…469` 后可重新触发。
- 打开地图时暂时隐藏对话框，返回后继续显示；暂停、拖动地图或传送均不能绕过点击放行。
