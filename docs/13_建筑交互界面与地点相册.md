# 建筑交互界面与地点相册

核对日期：2026-09-27

## 已完成

- 按用户参考图统一地图内建筑页面：奶油色面板、浅绿标题区、地点插画、黄／绿／桃色功能按钮、陶土色上传按钮及相册空状态插画。
- 保留左侧附近地图与个人信息、背景校园、原有功能和返回原位流程。
- 图书馆、教学楼群、体育场（副场）、二食堂、升华公寓均提供地点相册。食堂与宿舍新增上传入口及上传期间的关闭保护。
- 五类地点均使用独立的“地点相册”页签；其他功能页面不显示相册。体育场相册不依赖社团与活动接口成功加载。
- 切换页签保留上传状态和已有照片；食堂评价草稿、公寓聊天输入保留。上传期间即使切到其他页签，返回校园仍会受关闭保护。
- 相册按既有 placeId 保存；教学楼群共用一个地点相册，升华公寓共用一个地点相册。
- 默认启用本机照片上传，沿用 PNG/JPEG/WebP/GIF、单张 10 MB 设置。可用 CAMPUS_IMAGE_POLICY=pending 显式关闭上传；旧 dev 配置仍兼容。

## 使用

启动前端与本机数据服务，靠近建筑按 E 进入。点击顶部独立的“地点相册”页签，再点击“上传图片”，选择一张照片。点击缩略图可看大图，关闭大图后继续操作。切换回原有功能页签时，相册内容隐藏。

照片保存在本机项目 data/ 目录中，重新进入或刷新页面后仍可读取。上传期间返回校园会保留当前面板；上传结束后可返回。上传功能依赖数据服务运行，不上传到云端。
