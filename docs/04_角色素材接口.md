# 中南大学像素校园｜角色素材接口

版本：1.0.0  
日期：2026-09-26  
适用工作线：E（角色设计与动画素材）→ A（地图公共框架与集成）  
状态：接口与交付约定；目前无正式角色资产，本文不表示角色已制作、接入或验收完成。

## 1. 范围与责任

本接口用于接入 WASD 步行、按住 Shift 骑电动车、松开 Shift 恢复步行所需的角色外观与动画。骑行素材采用人物与电动车合一的画面，不增加找车、取车、还车或车辆装配系统。

| 工作线 | 负责内容 | 不包含的职责 |
|---|---|---|
| E | 角色设计样张、透明 PNG 精灵图、帧及锚点元数据、素材来源与使用条件、交付预览 | 输入控制、移动速度、地图坐标、镜头、碰撞及公共代码 |
| A | 素材加载、动画选择与播放、显示比例、世界落地点、移动与碰撞、遮挡、输入暂停和集成验收 | 代替用户确认人物外观，或将临时测试素材认定为 E 成品 |

角色外观、画布像素尺寸、动作帧数尚未确定。E 先提交样张，由 A 放入当前地图进行比例和遮挡预览，再交用户审阅。本文规定的数据结构和朝向算法是实现约定，不是已完成角色资产，也不代表上述美术参数已获确认。

## 2. 目录与交付物

建议按以下目录交付；文件和目录名只用于组织素材，不预设人物外观：

| 目录 | 内容 |
|---|---|
| `assets/characters/source/` | 可编辑源文件、参考资料、来源及使用条件说明、样张和审阅记录 |
| `public/characters/student/` | 供应用加载的透明 PNG 精灵图与 `manifest.json` |

正式交付应包括实际 PNG、与之匹配的 manifest、状态预览和来源说明。精灵图可以是一张或多张，由 `sheets` 声明；不要求把所有模式强行放入同一尺寸的画布。

目前上述正式素材尚未交付。不得仅为补齐目录创建假成品 PNG 或虚构 manifest，也不得把 A 的临时测试素材计入 E 的完成结果。

E 仅在约定素材范围内工作，不修改应用入口、依赖配置、共享类型、移动代码、地图或碰撞数据。公共接口变更先由 A 统一处理，再同步本文。

## 3. manifest 契约

下列字段与[项目统一类型声明](contracts/campus-v1.d.ts)保持一致，不另建一套角色数据结构。

### 3.1 CharacterManifest

| 字段 | 类型与要求 |
|---|---|
| `schemaVersion` | 固定为数字 `1` |
| `characterId` | 非空字符串，用于标识该角色素材包 |
| `sheets` | `SpriteSheet[]`，列出实际交付的精灵图 |
| `clips` | `CharacterClip[]`，覆盖第 4 节要求的 16 个状态入口 |

### 3.2 SpriteSheet

| 字段 | 类型与要求 |
|---|---|
| `id` | 非空字符串；同一 manifest 内唯一 |
| `url` | PNG 文件路径，**相对 manifest 所在目录**解析；不得使用操作系统绝对路径或外站 URL |
| `width` | PNG 的实际像素宽度，正整数 |
| `height` | PNG 的实际像素高度，正整数 |

`width`、`height` 是对已交付文件的描述，不是提前锁定的美术尺寸。A 应核对图片解码后的实际尺寸与声明一致。

### 3.3 CharacterClip

| 字段 | 类型与要求 |
|---|---|
| `mode` | `'walk'` 或 `'ride'` |
| `facing` | `'up'`、`'down'`、`'left'` 或 `'right'`，均为屏幕方向 |
| `action` | `'idle'` 或 `'move'` |
| `loop` | 布尔值；首版这 16 个状态入口均为 `true` |
| `frames` | 非空 `SpriteFrame[]`，数组顺序就是播放顺序 |

同一组 `mode + facing + action` 只能出现一次。待机可以只有一帧；移动帧数和各帧播放时长由 E 样张验证后确定。

### 3.4 SpriteFrame

| 字段 | 类型与要求 |
|---|---|
| `sheetId` | 字符串，必须对应已声明的 `SpriteSheet.id` |
| `rect.x`、`rect.y` | 当前帧在精灵图中的左上角位置，非负整数像素 |
| `rect.width`、`rect.height` | 当前帧宽高，正整数像素 |
| `anchor.x`、`anchor.y` | 当前帧局部像素坐标中的地面落地点，见第 5 节 |
| `durationMs` | 当前帧持续毫秒数，有限且大于 0；单帧待机也须提供有效值 |

帧矩形不得越界：`rect.x + rect.width ≤ sheet.width`，且 `rect.y + rect.height ≤ sheet.height`。矩形取自对应 `sheetId` 的精灵图，而不是另一张图的尺寸。

## 4. 必需状态与屏幕朝向

最小素材覆盖为 **2 种模式 × 4 个屏幕方向 × 2 种动作＝16 个状态入口**：

| 模式 | 屏幕方向 | 动作 |
|---|---|---|
| `walk` | `up`、`down`、`left`、`right` | 每个方向均有 `idle` 和 `move` |
| `ride` | `up`、`down`、`left`、`right` | 每个方向均有 `idle` 和 `move` |

`up` 表示朝画面上方，`down` 表示朝画面下方，其余类推。它们不能命名或解释为地理北、南、东、西。地图画面朝向不锁定为北朝上；本接口也不增加旋转视角要求。

A 负责按以下技术默认选择朝向：

1. 比较屏幕水平、垂直两个速度分量的绝对值，取较大分量所在轴的方向。
2. 两轴绝对值相等且正在移动时，取水平方向。
3. 停止移动时保留上一次朝向，不因速度归零切回默认方向。

斜向移动的速度归一化由 A 负责。E 无须制作八方向动画。角色初次出现时的初始朝向由 A 的场景配置决定，不能把“停止保留上次方向”误作首次初始化规则。

## 5. 锚点、比例与碰撞

`anchor` 的原点是**当前帧裁切矩形的左上角**，不是精灵图左上角，也不是地图原点。横坐标向右增加，纵坐标向下增加。所有锚点均使用当前帧局部像素值，不使用百分比或归一化数值。

- 步行锚点表示角色脚底与地面相接的位置。
- 骑行锚点表示人车整体对应的车轮地面落点参考；E 须在预览或说明中标明选取方式，并在各帧保持一致含义。
- 锚点应位于当前帧画布内或其边界上；帧可以带透明留白，但不得依靠变动留白造成落地点漂移。

A 将这个锚点对齐角色的世界落地点。换帧、切换朝向、按下或松开 Shift 时，外观可以变化，世界落地点必须保持不变，不因精灵图尺寸变化而跳动。

显示比例由 A 按模式配置，并在地图合成预览中与 E 一起检查；不得从尚未确认的固定人物像素尺寸反推地图尺度。渲染应保留像素边缘，不以横纵不一致的拉伸修正比例。

**角色图像大小不等于碰撞范围。** A 单独决定步行及骑行的足底碰撞体、模式缩放、速度和遮挡排序。E 不在 manifest 中添加运行时速度、世界坐标或碰撞形状字段。画面上更宽的电动车也不能自动获得穿越障碍的能力。

`durationMs` 控制动画节奏，不等于移动速度；A 不得仅通过动画播放快慢宣称已实现骑行速度要求。

## 6. 分阶段交付

| 阶段 | E 交付 | A 配合与阶段出口 |
|---|---|---|
| E1：设计样张 | 步行与人车合一骑行的四方向样张、候选实际像素尺寸、落地点标注、来源说明 | 放入当前最终地图生成预览，检查比例与辨识度，提交用户审阅；未审阅参数保持待确认 |
| E2：动画小样 | 步行与骑行移动动画小样，展示帧尺寸、锚点及播放节奏 | 验证解析、脚底/轮胎稳定性、Shift 切换和地图遮挡；确认可接入后再完善全套 |
| E3：完整素材包 | 16 个状态入口、实际 PNG、完整 manifest、源文件与来源记录、状态预览 | 校验素材契约并接入运行程序，执行第 7 节验收 |
| E4：问题修订 | 修复验收发现的裁切、抖动、比例或状态缺失，更新对应元数据与预览 | 对修订影响范围复验，记录实际通过项和仍未通过项 |

A 可以使用明确标注的临时测试素材提前开发加载器、状态切换和碰撞逻辑，但临时素材验证只证明相应运行逻辑，不代表 E 已交付或正式美术已验收。

## 7. A 接入与素材验收

| 验收面 | 通过条件 |
|---|---|
| 文件与契约 | PNG 可读取且带真实透明背景；路径为相对路径；图片尺寸与声明一致；sheet ID 唯一且引用有效；帧矩形不越界；时长有效 |
| 状态覆盖 | 16 个组合均存在且无重复；均可加载播放；待机允许单帧；`loop` 均为 `true` |
| 视觉质量 | 无底色、白边、人物或车轮裁切；像素边缘清晰；四方向可辨识；未经审阅不得依赖镜像破坏服装或车辆的左右不对称细节 |
| 锚点稳定 | 同一动画换帧不发生非预期抖动或滑移；换向、步行/骑行切换后世界落地点不变 |
| 操作与朝向 | WASD 步行；按住 Shift 显示骑行，松开恢复步行；斜向遵循第 4 节规则；停止保留朝向并播放对应待机 |
| 运动与碰撞 | 斜向速度由 A 归一化；两种模式都遵守碰撞；模式切换不把角色推入建筑、水体或其他障碍；碰撞不直接取图片外框 |
| 地图合成 | 使用当前最终底图验证显示比例、脚底落地和建筑/树木前后遮挡，不能仅在孤立素材预览中验收 |
| 输入中断 | 打开功能界面、表单、图片选择或大图查看，以及窗口失焦时，A 停止角色移动并清理按键状态，避免残留的 WASD 或 Shift 造成误移动 |
| 交付记录 | 保留实际文件、来源条件、审阅结果和通过/未通过项；临时测试素材与正式成品清楚区分 |

素材文件有效、渲染正确、移动碰撞正确是不同层次的检查，应分别记录。任何未通过项保留为未完成，不能以“PNG 已生成”或“页面能打开”替代整体完成。
