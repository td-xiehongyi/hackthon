# 全流程背景音乐

已接入用户提供的「主页背景音乐.mp3」，项目资源为 `public/audio/campus-background.mp3`，复制后 SHA-256 与原文件一致。

## 使用

- 首页右上角的音符按钮打开音乐设置；进入游戏后，右下角保留音乐设置按钮。
- 首次点击或按键后开始播放，整首循环。首页、地图、教学楼、宿舍和场景导入页面共用播放器，普通页面切换保留播放进度。
- 点击「开始校园跑」后切换为用户提供的「校园跑音乐.mp3」（`public/audio/campus-run.mp3`），跑步及骑行提醒期间循环播放。完成一圈、离开校园跑栏目或返回校园后恢复主页背景音乐。切换曲目从头播放，音量、静音及主动暂停选择保持不变。
- 校园跑骑行警告的语言框出现、南门警察头盔语言框出现时，播放用户提供的 `milkfrog_gaga_dilaxia.wav`（`public/audio/police-warning.wav`）。提醒音播放一次，期间暂停背景音乐；播完或提前关闭语言框后，从原暂停位置继续当前背景音乐。退出场景会停止提醒音；加载失败会恢复背景音乐。提醒音也沿用音量、静音和主动暂停选择。
- 默认音量 40%，可调节 0–100%，支持静音、暂停和继续播放。
- 音量与静音保存在当前浏览器，刷新后恢复。主动暂停后，其他点击不会重新开启音乐；刷新页面后重新尝试播放。
- 浏览器禁止自动播放时，需先点击页面。浏览器或操作系统冻结后台标签页时，实际播放受系统限制。
