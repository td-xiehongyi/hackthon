# 碰撞与通行规则

更新：2026-09-26。项目：中南大学像素校园；工作目录：`C:\Users\xie\Desktop\多人\hackthon`。

## 本次规则

- 草地开放，麓南运动场、潇湘体育场副场和鸟巢内部开放，场内底图标牌不阻挡角色。
- 道路、步道旁和建筑附近的树木可通过。当前邻域参数为道路/步道向外 40 原图像素、建筑向外 32 原图像素，使用方形邻域；远离这些范围的成片树林未统一开放。
- 窄路允许骑行：步行和骑行均使用 8×4 原图像素的脚底碰撞框。骑行仍为 120 px/s，步行为 60 px/s；速度仍是开发参数。每次移动完整检查碰撞框，并按不超过 1 像素的小步推进。
- 玉带湖斜桥、过街天桥及玉带湖东侧木桥可进入；斜桥东南接岸已补齐。后湖西岸栈道及东侧凉亭栈道也有局部通行范围，但东侧凉亭位于画面边缘，其外部接路关系没有验收。
- 建筑与水面保留阻挡。桥面在生成蒙版时切出通道，运行时继续使用统一碰撞规则。

## 数据与维护

人工修正源是 [campus-v20.navigation.json](../assets/maps/campus-v20.navigation.json)，包含地图身份、邻域距离、操场放行区、建筑阻挡、水域阻挡和桥面通道。这里的建筑轮廓仅服务碰撞，不是正式楼座目录，也不会生成地点入口。

生成顺序：道路/草地颜色识别 → 小装饰孔洞与碎片处理 → 路旁和建筑周围放行 → 操场放行 → 水域扣除 → 桥面连接 → 建筑扣除。后续手工登记的 `collisionAreas` 在运行时仍具有阻挡优先级。

在项目目录运行 `npm run map:annotate`，会重新生成：

- `assets/maps/campus-v20.walkable.png`：通行蒙版。
- [campus-v20.walkable-check.png](../assets/maps/campus-v20.walkable-check.png)：检查图；黄为原步道，蓝为原道路，绿为开放草地/树木/操场/桥，红为阻挡。
- `public/maps/campus-v20.annotations.json`：运行时通行多边形。

请修改独立修正源再重新生成，避免直接修改生成的矩形。地图 SHA-256 或尺寸不匹配时生成工具拒绝覆盖；已有互动入口、安全点、楼座、遮挡和手工碰撞区域会保留。

当前产物为 3508 个通行矩形，通行像素约 84.6%。像素连通块数量不等于完整角色可达区域；测试另外使用真实脚底碰撞框搜索连通性。
